adoq QDA

Analyse de données qualitatives · logiciel libre

Un logiciel pour apprendre le codage qualitatif d'entretiens, pensé pour les étudiant·es et leurs enseignant·es.

On y importe ses retranscriptions, on surligne des passages, on leur attribue des codes, on organise ces codes en arbre et on compare son codage avec celui d'un·e collègue. Ce sont les gestes de base de l'analyse qualitative assistée par ordinateur, réunis dans un outil volontairement simple.

Toute l'application tient dans un seul fichier HTML : rien à installer, pas de compte à créer. Un double-clic l'ouvre dans le navigateur, elle fonctionne hors ligne et aucune donnée n'est envoyée sur internet.

Ce qui le distingue

  • Un projet = un fichier texte (.qda.md), lisible dans n'importe quel éditeur. Le codage n'est pas enfermé dans une boîte noire : on voit exactement ce qui a été noté.
  • Questions et réponses distinguées ; les locuteurs ont un pseudo et des caractéristiques (âge, genre, profession…).
  • Une grille d'analyse tracée : chaque création, fusion ou déplacement de code est consigné dans un journal, avec son motif.
  • Coder à deux : mesure de l'accord entre codeurs (kappa de Cohen) et construction d'un codage de consensus.
  • Vue enseignant pour suivre le travail d'un groupe d'étudiant·es.

Pour qui ?

adoq QDA convient pour découvrir l'analyse qualitative, préparer un mémoire avec une dizaine ou une trentaine d'entretiens, analyser des focus groups ou enseigner la méthode. Il n'est en revanche pas conçu pour les grands corpus d'équipes de recherche professionnelles : il laisse volontairement de côté le travail simultané, la gestion des droits d'accès, le codage audio et vidéo et les requêtes avancées.

Un format ouvert : qda.md

Les projets sont enregistrés au format qda.md, un format Markdown en texte brut pour les données qualitatives codées. Un même fichier contient les textes, l'arbre de codes, les codages, les mémos et l'historique de la grille. Chaque codage est une ligne lisible, signée par son codeur et liée à une citation exacte. Le fichier s'édite aussi dans Obsidian et ne dépend d'aucun logiciel particulier. Ce format est partagé avec QDA-md, l'outil de codage qualitatif pour la recherche dont adoq QDA est la version pédagogique.
